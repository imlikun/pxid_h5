## 一、个人主页（H5，已上线，明天 Flutter 接）

### 1. 产品逻辑

- **一个「人」出现的地方，点它就能进这个人的主页**——点谁的头像/昵称进谁的页面，点自己进自己的主页。
- 主页核心内容 = **这个人的动态流**（TA 发过的帖），数据复用发现页 feed 体系。
- 自己的主页与 Flutter「我的」tab 分工：原生「我的」= 个人中心（功能入口）；H5 主页 = 我的动态流（社区内容）。

### 2. 页面结构（`src/views/UserProfileView.vue`）

- 顶栏：昵称 + 返回（侧滑返回通用）
- 资料卡：大头像 / 昵称（自己显示「我」角标）/ 车型标签 / 关注数·粉丝数 / 关注按钮
- TA 的动态：复用 MomentCard，触底分页加载，空态「暂无动态」
- 关注按钮：他人可关注/取关（乐观更新 + 后端落库）；自己隐藏按钮

### 3. 接口（后端已实现）

| 接口                                   | 说明                                                                                                                                 |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `GET /users/:deviceId`               | 聚合：nickname/avatar/carModel（取最近发帖）+ followeeCount/followerCount（follows 表）+ isFollowing/isSelf（可选身份：带有效 Bearer token 才解析；未登录可公开访问） |
| `GET /feed?tab=dynamic&deviceId=xxx` | 某人动态流（新增 deviceId 过滤，分页 page/pageSize 同发现页）                                                                                        |
| `POST /follow` / `DELETE /follow`    | 关注/取关（已存在）                                                                                                                         |

### 4. 入口（已接入，`@click.stop` 防卡片跳详情冲突）

- 动态列表推荐卡（FeedCard）作者区 → `/user/:deviceId`
- 动态列表动态卡（MomentCard）作者区 → `/user/:deviceId`
- 动态详情页作者卡 → `/user/:deviceId`（官方帖无 deviceId 不跳）
- 互动消息「关注了你」→ `/user/:actorDevice`（后端已返回 actorDevice）
- 自己的主页 `/user/me`：路由已支持，用本机 getDeviceId() 识别

- [ ] 备注：他人主页入口已全部在 H5 内闭环，Flutter 无需处理
