# 发现页动效

日期：2026-10-10。

采用操作触发的短反馈，沿用现有布局、颜色和图片排布，不新增动画库。

- 发现与精选共用顶部标签：文字颜色和蓝色下划线在 160ms 内过渡；按下时文字短暂变淡。保留原字号、间距、点击区域及下划线位置。
- 动态/话题车型菜单：160ms 淡入并向下移动 3px，箭头同步转动。菜单仍为浮层，不推动卡片；关闭立即完成，保留点击外部、Esc 和键盘选项导航。
- 推荐卡片及动态列表图片：解码完成后从 70% 不透明度过渡到 100%，持续 160ms。同一图片不重复播放；不改变尺寸、不等待整批图片、不隐藏已有内容。详情页 eager 图片沿用直接显示。
- 沿用现有按钮按下、搜索展开和轮播切换反馈。系统设置“减少动态效果”时，关闭此次标签、菜单、箭头、图片动效及发现页搜索/按下位移动效。

## 验证

- `tests/discover-motion-checks.mjs`：10 项实际浏览器检查，覆盖卡片位置稳定、菜单焦点与 Esc、标签几何、图片尺寸/可见性/重复进入，以及减少动态效果。
- `tests/discover-ui-checks.mjs`：40 项发现回归检查通过，包含 1–9 图、直板与折叠屏、筛选、话题、互动、详情返回和请求竞态。
- 发现/精选顶栏另执行 24 项浏览器检查；中文、英文、葡语在 375 / 390 / 430 / 600 / 1017 / 1337px 下字号、位置、下划线与控件布局一致。
- 动效与交互写请求使用本地隔离数据；顶栏对齐检查仅读取公开接口。以上为浏览器检查，未替代 Flutter 实机验收或真实用户性能指标。
