## 1. 发现页（社区）界面结构（来自站酷拆解）

**推荐首页布局（从上到下）**
```
导航（搜索）
 └─ Banner（官方 H5，分大类，可分享 / 参与话题）
 └─ 分类导航：用车攻略 / 购车攻略 / 车友故事 / 预约试驾
 └─ 信息流（双列或列表；列表详情内嵌「推荐合集 / 特辑」非单一详情）
```
- 图片用官方品牌图，强品牌感。
- 截图隐私提示：截屏弹窗提醒删隐私截图（站酷评「过于频繁，应在隐私页才提醒」）——**可借鉴但需克制**。

**动态页**
```
动态（导航栏）
 ├─ 排序：最新 / 最热（最热曝光更高）
 ├─ 发布动态：选话题分类
 ├─ 话题排行（看高热度话题）
 └─ 内容区分：官方内容带顶部大图 + 标题；用户内容直接展示正文高光
```

**活动页**（PXID 当前缺失、最该补的模块）
```
活动首页
 ├─ Banner（大占比，突出官方活动）
 └─ 活动内容卡片（横向滑动，一条条展开查看）
活动详情页
 └─ 可参加活动 → 获得华为周边商品（引流机制）
```

**附近板块**（PXID 可参考的本地化能力）
- 用户本地化交流入口；发布信息在「附近」专栏展示；可切换城市看其他城市动态。

**消息**
- 系统消息 + 动态消息（点赞 / 评论通知），产生互动。

## 2. 精选（商城）界面结构
```
精选
 ├─ Banner
 └─ 车载商品列表（按分类分组）
```
- 车辆型号在「智选/购车」导航下突出性能配置，可预约/订购。
- 支持积分抵扣（我的积分/我的权益在 v1.1.4.300 新增）。

## 3. 官方改版日志暴露的功能演进（证明活动/积分是后加）
> 来源：AITO App 安卓 v1.1.4.300 改版说明（shichang360）

新增：【精选】购物频道、【预约服务】、【我的积分】、【我的权益】、调整【动态】字数上限、新增【活动】入口。

**启示**：问界也是「先有基础社区，后补活动/积分/权益」——印证 PXID 把活动/积分放后续版本（本文档前一版 §2 D 类）是合理的，但**活动入口与独立活动详情页应尽早立**（问界把它做成一级流量位）。

## 4. 对 PXID 的设计对标启示

| 问界做法 | PXID 现状 | 建议 |
|---|---|---|
| 活动 = 一级流量位（Banner+横滑卡片+详情报名得周边） | 活动降格为 content_type 标签 | 立独立活动模块（见「完整产品功能文档」§3.2） |
| 官方内容带顶部大图+标题，用户内容直出 | 未区分 | 发布/详情页区分官方 vs UGC 视觉 |
| 动态：最新/最热排序 + 话题排行 | 仅关注流 | 加排序 + 话题 |
| 附近板块（切城市） | 无 | 电助力车弱本地化，可暂缓 |
| 消息：系统+互动通知 | 铃铛桩页 | 补消息中心（D 类） |
| 我的积分 / 我的权益 | 入口有、账本未启用 | 启用积分体系（D 类） |
| 截图隐私提示（克制版） | 无 | 发布含隐私页时轻提示 |

---

## 5. 一句话结论
问界官方设计文档不公开，但**站酷 UX 体验日记已给出发现/动态/活动/消息的页面信息架构级拆解**，足够作为 PXID 运营侧（尤其是缺失的活动模块、官方 vs UGC 区分、动态排序/话题）的界面设计对标。建议把「活动模块」「消息中心」「官方/UGC 视觉区分」优先补进 PRD v1.2。
