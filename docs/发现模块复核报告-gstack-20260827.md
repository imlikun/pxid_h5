## 🔴 严重（6）

1. **`FeedDetailView.vue:21,26` `isOfficial` 未定义** — 官方帖徽标永不显示，且每条官方帖都显示「关注」按钮，点击后因 deviceId 空弹「关注失败」。建议改 `item.kind === 'official'`（rowToFeed 已返回 kind）。

2. **`FeedDetailView.vue:585-589` 收藏 `onCollect` 无任何后端调用** — 只 toggle + toast，不落库，退出即丢；「点赞/收藏/关注」三件套只有收藏是假的。需后端 `POST /feed/:id/collect` 或明确降级。

3. **`UserProfileView.vue:134-139` 个人主页无路由 watch，`/user/A → /user/B` 串页** — App.vue 全局 keep-alive 缓存组件，只有 onMounted 无 `watch(() => route.params.id)`；从 A 主页进 B 主页显示 A 的数据。需加 watch 重拉。

4. **deviceId 双源不一致** — `utils/device.js`（localStorage）与 token 内 deviceId 是两套 ID；`/user/me` 用 localStorage ID 查不到帖子 → 「骑友」占位、动态流空、`isSelf=false` → 自己主页出现「+ 关注」按钮。建议 `/users/me` 由后端从 token 解析，前端不再自报。

5. **`MomentCard.vue:106-118` 列表点赞/关注走 openNative 契约** — 与详情页（FeedDetailView.onLike 直连后端、带身份、有回滚）不一致；乐观更新无回滚，H5 预览 mock 无映射 → 静默失效只改图标。若 Flutter 已实现 feed/interact、feed/follow 则闭环（待确认）；建议统一直连或失败回滚。

6. **`PublishView.vue:389-455` 发帖闭环** — 真机 openNative 只传正文，车型/图片/视频/位置/@提及全丢；Flutter 发布器未实现则真机断链；`api/feed.js` 的 `publishFeed()`（含本地兜底）无调用方，后端抖动即丢帖。建议真机补传参数、H5 兜底走 publishFeed。

9. **广场 showcase 不随地区** — 三区同图（待 ToC 车型 API）。
