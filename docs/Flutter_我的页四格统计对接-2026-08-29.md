# 我的页_四格统计与个人主页_Flutter对接

> 对接双方：Flutter App（tocApp）× 八戒 H5（`https://appin.site/nav/pxid-h5/`）
> 文档日期：2026-08-29
> 适用范围：我的页「发布 / 收藏 / 关注 / 粉丝」四格入口 → H5 个人主页 Tab

---

## 一、背景（Flutter 侧现状）

### 1.1 我的页结构

tocApp 的「我的」页是 **Flutter 原生页**（`MinePage`），四格统计入口在用户资料卡下方。

**四格对应入口：**
| 入口名（中文） | 入口名（l10n key） | 当前显示值 | 对应 H5 Tab 链接 |
| --- | --- | --- | --- |
| 发布 | `posts` | 0（占位） | `https://appin.site/nav/pxid-h5/#/user/me?tab=publish` |
| 收藏 | `favorites` | 0（占位） | `https://appin.site/nav/pxid-h5/#/user/me?tab=favorites` |
| 关注 | `following` | 0（占位） | `https://appin.site/nav/pxid-h5/#/user/me?tab=follow` |
| 粉丝 | `fans` | 0（占位） | `https://appin.site/nav/pxid-h5/#/user/me?tab=followers` |

跳转链路：

```
Flutter 我的页 四格 onTap
  → Flutter push 一个 WebViewPage（showAppBar=false，双桥注入）
    → 加载对应 H5 URL（`#/user/me?tab=xxx`）
```

### 1.2 Flutter 侧已确认的红线约束

1. **四格 UI 样式不变**：字号、颜色、间距、四格比例全部保持原有 MinePage 设计，**不允许 Flutter 侧修改**。
2. **顶部只留状态栏安全区**：不写原生 AppBar（不写标题、不写返回按钮）。八戒 H5 自己有顶部标题栏与返回按钮。
3. **H5 返回按钮必须回到 Flutter 的「我的」页**，而不是：
   - 在 H5 内部切路由（例如从 `tab=publish` 回退到 `tab=favorites`）
   - 或点击后静默没反应

## 二、Flutter 需要八戒配合的三件事（请八戒按此实现）

### 🔴 2.1 提供「四格真实值」的接口或字段（本次必须）

#### 方式 A（推荐）：在现有的 H5 用户信息接口里扩展四个统计字段

H5 的 `/user/me` 或现有 `getUserInfo` / 用户资料接口返回对象中，**额外返回一个 `stats` 对象**，包含：

```ts
{
  // ... 现有的 nickname / avatar / deviceId 等字段不变 ...

  stats: {
    posts:     number, // 发布/动态数量（对应「发布」格）
    favorites: number, // 收藏数量（对应「收藏」格）
    following: number, // 关注数量（对应「关注」格）
    followers: number, // 粉丝数量（对应「粉丝」格）
  }
}
```

**字段名固定，不要改。** 类型必须是安全整数，`>= 0`。如果某个维度暂时无数据，返回 `0`，不要返回 `null` / `undefined`。

---

#### 方式 B：独立一个统计接口（可接受）

如果八戒不方便改动现有用户资料接口，也可以新增**独立接口**：

```
GET /user/stats/me
```

**要求：**
- 鉴权方式与其他 H5 用户接口一致（tocApp WebView 里已注入 PXIDBridge token，按现有方式带即可）。
- 返回结构同上（顶层 `code == 0` 视为成功）：

```json
{
  "code": 0,
  "data": {
    "posts": 38,
    "favorites": 12,
    "following": 6,
    "followers": 251
  },
  "msg": ""
}
```

---

> **为什么字段名必须统一？**
> Flutter 侧当前显示文案的 l10n key 就是 `posts / favorites / following / fans`。为了让 Flutter 不用再做一层别名映射，接口返回按上面四个字段名来，后续双方都省事儿。
> （注意：粉丝字段 Flutter 展示叫 `fans`，但接口建议用 `followers`，更贴合后端 H5 数据库表字段命名，Flutter 会把 `followers` 映射到我的页第 4 格，这个映射 Flutter 自己做，八戒不用管。）

---

### 🟠 2.2 H5 返回按钮：必须调 `window.PXIDApp.postMessage('closeWebView')`（本次必须）

#### 背景说明

Flutter 打开个人主页时使用的是全屏 WebView，**原生栈顶只有一个页面**。八戒 H5 自己有返回按钮，Flutter 不提供原生 AppBar 返回按钮。

此时如果 H5 的返回按钮只做普通 `history.back()` / `router.back()`：
- Flutter 侧**不会知道**用户点了「返回」
- 用户会停留在 WebView 里继续切 H5 路由，达不到「点返回就回到我的页」的效果

**所以八戒必须这样实现返回按钮：**

```js
function onBackClicked() {
  // ① 先判断是否是原生容器环境
  const isNative =
    typeof window !== 'undefined' &&
    typeof window.PXIDApp !== 'undefined' &&
    typeof window.PXIDApp.postMessage === 'function'

  if (isNative) {
    // ② 原生环境：通知 Flutter 关闭当前 WebView，回到 Flutter 的「我的」页
    window.PXIDApp.postMessage('closeWebView')
    return
  }

  // ③ 非原生环境（浏览器直接打开 H5）：走普通返回
  window.history.back()
}
```

#### Flutter 侧已支持

对应实现已在 `WebViewPage`：

- 注册 JS Channel：`PXIDApp`
- 收到消息 `closeWebView`：执行 `Navigator.of(context).pop()` 回到上一页（即「我的」页）

> **⚠️ 注意**：不要用 `window.PXIDBridge.closeWebView()`，这个方法不存在。关闭 WebView 的桥就是 **`PXIDApp.postMessage('closeWebView')`**（和积分页返回的用法完全一致）。

### 🟡 2.3 Tab 参数值最终确认（请八戒按此给最终字符串）

当前 Flutter 按八戒给的 4 个链接直接透传：

| 入口 | H5 URL hash fragment |
| --- | --- |
| 发布 | `#/user/me?tab=publish` |
| 收藏 | `#/user/me?tab=favorites` |
| 关注 | `#/user/me?tab=follow` |
| 粉丝 | `#/user/me?tab=followers` |

但根据之前的《用户主页_Flutter对接.md》，H5 个人主页有六个 Tab：`动态 · 赞过 · 收藏 · 关注 · 粉丝 · 足迹`，没明确提到「发布」Tab。

**需要八戒确认（本次必须答复）：**

1. `tab=publish` 是否等价于「动态」Tab？
2. 还是说「发布」是一个独立 Tab（对应我发布过的 Feed 列表）？
3. 四个 tab 参数值就是上面这四个字符串吗？有没有别名或大小写差异？

> **Flutter 侧行为**：在八戒最终确认前，Flutter 会先按你给的这四个字符串直接拼 URL 打开；如果后续确认值不对，Flutter 只改 map 映射，不改 H5 页面。

## 三、Flutter 侧会做的事情（不用八戒改任何 H5 页面结构）

### 3.1 四格跳转 Flutter WebViewPage 打开参数

```dart
WebViewPage(
  initialUrl: 'https://appin.site/nav/pxid-h5/#/user/me?tab=xxx',
  showAppBar: false,                          // 不写原生标题栏/返回
  enableCloseWebViewBridge: true,             // 启用 PXIDApp.closeWebView
  enablePXIDBridge: true,                     // 启用 PXIDBridge（getUserInfo / token）
)
```

对应效果：
- 顶部自动留出 SafeArea（系统状态栏信息横条）
- 不出现原生 AppBar，八戒 H5 的顶部标题栏会贴在系统状态栏下方
- 八戒点返回通过 `PXIDApp` 能正确回到 Flutter 我的页

### 3.2 如果八戒提供了 stats 接口或字段，Flutter 会自行取值并展示真实数字

- **取值时机**：进入「我的」页时拉一次；用户从 H5 返回时再拉一次（避免发布/取关后数字对不上）。
- **展示规则**：
  - `<= 99`：直接显示原数字
  - `> 99`：显示 `99+`（与铃铛徽章口径一致，按 Flutter 现有 UI 偏好）

> 如果八戒提供的接口本身有返回 `99+` 字符串，Flutter 会直接显示；否则 Flutter 自己做截断。
