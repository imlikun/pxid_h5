## 三、Bug 清单（对应内部跟踪系统逐条）

### Bug #1：关注 — 无论登录状态都跳转登录

- **现象**：已登录状态下点"关注"仍弹登录页
- **代码现状**：H5侧 `requireLogin()` 已加兜底（755912d），检测 getUserInfo 返回的 email/nickname/token 任一即放行
- **根因**：Flutter 侧 `bridge.getUserInfo()` 真机未返回有效用户资料（或返回空对象），导致 H5 判定"未登录"
- **解决方案**：
  - **短期**：Flutter 侧确保登录后 `getUserInfo()` 返回 `{email, nickname, token}`（任一非空）
  - **长期**：走 F1 契约的 `bridge.getToken()` 注入登录 token 到 H5
- **需要支持**：🔴 Flutter 侧提供真机 `getUserInfo()` 日志 + 确认 token 注入方案
- **验收标准**：真机登录后点关注 → 不弹登录 → follow请求带token成功200

### Bug #2：评论输入框被键盘遮挡

- **现象**：评论时看不到输入框，被输入法界面挡住
- **代码现状**：已修复（755912d）——聚焦时变 position:fixed 底部栏 + visualViewport 计算键盘高度
- **根因**：原 `.cinput` 是内联流元素，键盘升起后被遮挡
- **需要支持**：🟢 无（纯H5侧修复）
- **验收标准**：真机点评论框 → 键盘弹出 → 输入栏浮在键盘正上方 → 可输入发送
- **⚠️ 注意**：visualViewport API 在部分旧 WebView 可能不支持，需真机验证；不支持时降级为 `window.innerHeight` 差值计算

## 四、事故根因分析（为什么反复回滚）

### 2026-08-26 回滚事故链

```
时间线：
  4f9f8f8 (15:43) 车型接真实数据 → 好版，含全部修复
    ↓
  4612bfa (16:34) 改立即订购跳转 → git仓库坏了(坏标签v1.0.0)
    ↓ 用 update-ref + reset --mixed 恢复
    ↓ 恢复后工作区不可信，但没 diff 核对
    ↓ 用 git add -A 盲扫提交 → 把旧版DiscoverView带入
    ↓ 结果：汉字回来、排序回来、banner变router.push
    ↓ 你看到的三处回滚 = 这一次盲提交导致
    ↓
  99b5bc7 (17:19) 从4f9f8f8恢复DiscoverView → 修回三处
    ↓
  8257e2a (17:30) banner改navigateTo → 修bridge方法用错
    ↓
  755912d (17:40) 5项bug根因修复 → 当前版本
```

**根本原因**：
1. `git add -A` 盲扫提交（不知道带了哪些文件）
2. 提交前不 `git diff HEAD --stat` 确认改动范围
3. git 仓库恢复后不核对工作区是否被污染

**已落地的杜绝措施**：
1. **彻底禁用 `git add -A`**，改精确路径 `git add <文件>`
2. **pre-commit 钩子**：提交 DiscoverView 时自动校验 4 个修复标记（汉字/openNative/compositionend/无onSort），缺一 abort
3. **提交铁律**：`git diff HEAD --stat` → 确认只有预期文件 → 精确 add → commit → push
