> 2026-08-26 · 坤哥

## 二、Token 注入链路（当前逻辑）

```
H5 调用 bridge.getAuthToken()
  ↓
① 优先取 getUserInfo().token
  ↓ （Flutter 未返回 token 字段或为空）
② 回退 getToken()
  ↓ （Flutter 返回的是 App 内部 token 或匿名 token）
③ 再回退 /auth/token 申请匿名 HMAC token
  ↓
发给后端 Authorization: Bearer <token>
  ↓
后端 ToC 校验 → 返回 401 "账号未登录"
```

**结论**：H5 代码逻辑正确，问题出在第①②步 Flutter 注入的值无效。

## 三、Flutter 侧需要做什么

### 3.1 必须实现的两个方法

按 `INTEGRATION.md` 契约，Flutter 在 WebView 加载前注入 `window.PXIDBridge`：

```javascript
// Android: JavascriptChannel
// iOS: WKScriptMessageHandler

window.PXIDBridge = {
  isNative: true,

  // 返回 ToC accessToken（关键！）
  getToken: () => Promise.resolve('真正的ToC_token'),

  // 登录用户资料（token 和 email 都必须有）
  getUserInfo: () => Promise.resolve({
    token: '真正的ToC_token',  // ← 这是后端校验用的
    email: 'user@example.com',
    nickname: '张三',
    avatar: 'https://...',
  }),

  // ... 其他方法
}
```

### 3.2 关键要求

| 方法              | 未登录时             | 登录后                                     |
| --------------- | ---------------- | --------------------------------------- |
| `getToken()`    | 返回 `''`（空串）      | 返回**有效的 ToC accessToken**               |
| `getUserInfo()` | 返回 `null` 或 `{}` | 返回 `{ token, email, nickname, avatar }` |

**注意**：

- `token` 必须是后端能识别的 ToC 登录 token，不能是 App 内部 token 或匿名 token
- 登录成功后必须立即更新这两个方法的返回值（H5 不刷新页面，靠值变化判断登录态）

### 3.3 验收方式

联调时在 Flutter 控制台打印：

```
Flutter → getUserInfo() 返回: {...}
Flutter → getToken() 返回: ...
```

同时在 H5 控制台打开 Console，搜索 `[PXIDBridge]` 日志，确认：

- `isNative` 为 `true`（不是 mock）
- `getUserInfo` 返回的对象里有 `token` 字段且非空

## 四、诊断三步走（给 Flutter 同事）

如果仍不确定，按以下顺序排查：

### 步骤 1：重新登录后立刻点签到

- ✅ 成功 → token 有效，但**过期快**（ToC token 有效期短）→ Flutter 需加"token 过期自动刷新"
- ❌ 失败 → token 根本不是 ToC 登录 token → 检查注入的值是什么

### 步骤 2：看 toast 具体文案（已上线）

| toast 文案       | 含义                         |
| -------------- | -------------------------- |
| "未授权：需要登录后操作"  | token 无效或未登录（Flutter 注入问题） |
| "Token 无效或已过期" | token 过期（需 Flutter 加刷新机制）  |
| "签到失败请重试"      | 网络/接口故障（与登录无关）             |

### 步骤 3：确认登录状态

App 登录后，检查 H5 里：

- 评论区发评论**带不带你的名字？**
- 头像**显示正常吗？**

如果完全没有身份信息 → `getUserInfo()` 没返回资料 → Flutter 两样都没注入。

## 五、后端期望的 Token 格式

后端 `server/server.js` 的 `requireAuth` 中间件逻辑：

```javascript
// 优先 ToC 校验（有 memberUserId）
if (user.memberUserId) {
  // ToC 登录用户，正常放行
} else {
  // 回退 HMAC 校验（匿名/预览模式）
  // 设备 ID 来自 token 或 body
}
```

**意味着**：

- 有效的 ToC token → `memberUserId` 有值 → 所有 growth 接口正常
- 无效的/匿名 token → `memberUserId` 为空 → 401 拒绝

## 七、如果 Flutter 侧暂时无法联调

H5 保持当前降级逻辑：

- 匿名用户可按 deviceId 签到攒积分（匿名 token 可用）
- 点赞/收藏/关注 401 时 toast 提示"需要登录后操作"
- 积分商城显示 mock 数据（无真实库存/余额）

这不是最终状态，只是过渡方案。
